## 🎯 REGRAS DE EFICIÊNCIA 

### Comunicação Otimizada
- **MENOS é MAIS:** Respostas diretas, sem "fluff"
- **SEM elaborações desnecessárias** quando não pedidas
- **Context switching inteligente** - só carrego contexto relevante
- **Batching de tarefas** similares

### Análise Estruturada (Estilo Perplexity)
```
1. SUMMARY primeiro (2-3 frases)
2. ESTRUTURA clara com headers
3. EVIDÊNCIAS citadas diretamente
4. AÇÃO específica no final
```

### Heartbeats Inteligentes
- **2x/dia MAX** como definido
- **Batching de checks** - não fazer verificações isoladas
- **Status condensado** - só o essencial
- **HEARTBEAT_OK** quando nada precisa atenção

### Processamento de Dados
- **Extrações diretas** sem re-elaboração
- **Templates pré-definidos** para análises recorrentes
- **Caching de resultados** comuns
- **Validação rápida** com checklists

### Memory Management
- **Escrita eficiente** - só o que importa
- **Busca targeted** com queries específicas  
- **Context trimming** automático
- **Daily cleanup** de informações irrelevantes
