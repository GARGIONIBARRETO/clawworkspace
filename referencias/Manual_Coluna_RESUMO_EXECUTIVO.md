# Manual de Codificação em Cirurgia da Coluna - RESUMO EXECUTIVO

## 📋 Sobre o Manual
- **Entidades:** SBC (Sociedade Brasileira de Coluna), SBOT (Sociedade Brasileira de Ortopedia e Traumatologia) e SBN (Sociedade Brasileira de Neurocirurgia)
- **Objetivo:** Padronizar codificações TUSS/CBHPM para procedimentos de coluna vertebral

## 🔑 Principais Categorias de Cobrança

### 1. **POR SEGMENTO** (multiplica pelo número de segmentos)
- **3.07.15.01-6** Artrodese com instrumentação (12C)
- **3.07.15.02-4** Artrodese via anterior/póstero-lateral (12C)
- **3.07.15.11-3** Espondilolistese (10A)
- **3.07.15.36-9** Tratamento microcirúrgico estenose (10B)
- **3.07.15.59-8** Artroplastia discal (12C)

### 2. **POR VÉRTEBRA** (multiplica pelo número de vértebras)
- **3.07.15.03-2** Biópsia da coluna (7C)
- **3.07.15.19-9** Laminectomia/laminotomia (9C)
- **3.07.15.22-9** Osteotomia vertebral (8C)
- **3.07.15.28-8** Substituição de corpo vertebral (10B)
- **3.07.15.38-5** Tumor ósseo vertebral (13C)

### 3. **POR ESTRUTURA** (forame, faceta, costela)
- **4.08.13.36-3** Infiltração foraminal/facetária (5A)
- **3.06.01.02-9** Costectomia (8B)
- **2.01.03.30-1** Infiltração ponto-gatilho (3A)

### 4. **UMA VEZ POR CIRURGIA**
- **3.07.15.05-9** Via endoscópica (11A)
- **3.07.15.16-4** Fratura/luxação - tratamento cirúrgico (12B)
- **3.07.32.02-6** Enxerto ósseo (9B)
- **4.08.11.02-6** Radioscopia intraoperatória (2B por hora)

## 💡 Dicas de Codificação

### ✅ LEMBRE-SE:
1. **Hérnias de disco:**
   - Lombar: 3.07.15.18-0 (10A)
   - Cervical: 3.07.15.39-3 (12B)

2. **Sempre incluir quando aplicável:**
   - Radioscopia (4.08.11.02-6)
   - Descompressão medular (3.07.15.09-1)
   - Laminectomia se realizada (3.07.15.19-9)

3. **Cirurgia 360° (anterior + posterior):**
   - 1º tempo: 100% código principal + 50% códigos secundários
   - 2º tempo: 75% de todos os códigos

4. **Monitorização neurofisiológica (2.02.02.09-1):**
   - Apenas para equipe de neuromonitorização
   - Não é repassado à equipe cirúrgica

## 🚨 Situações Especiais

### Complicações Intraoperatórias:
- **Fístula liquórica:** 3.14.01.26-0 (10C)
- **Lesão vascular abdominal:** 3.09.10.13-7 (12A)

### Procedimentos Percutâneos:
- **Vertebroplastia:** 4.08.14.09-2 (8C)
- **Rizotomia:** 3.14.03.33-6 (10C)
- **Denervação facetária:** 3.14.03.03-4 (9C)

## 📊 Estrutura dos Protocolos

Cada procedimento no manual contém:
1. **Descrição detalhada**
2. **CIDs aplicáveis**
3. **Indicações/Contraindicações**
4. **Códigos CBHPM** (principal + complementares)
5. **OPMEs necessários**
6. **Tempo de internação sugerido**
7. **Materiais especiais**
8. **Observações sobre codificação múltipla**

## ⚠️ Regras Importantes

1. **Multiplicação de códigos:** Sempre justificar baseado em:
   - História clínica
   - Exame físico
   - Exames complementares
   - Objetivos cirúrgicos

2. **Relatório cirúrgico:** Deve conter TODAS as etapas realizadas para evitar glosas

3. **Via de acesso endoscópica:** Cobra-se UMA VEZ independente do número de portais

4. **Infiltrações:** Multiplicar pelo número de estruturas infiltradas (direita/esquerda contam separadamente)

---
📌 **Dica Final:** Este manual é essencial para evitar glosas. Sempre documente adequadamente e use os códigos corretos conforme o número de segmentos/vértebras/estruturas abordadas.
